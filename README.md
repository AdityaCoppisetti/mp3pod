here are some questions you must be wondering 
1) did i use ai for this project?
   - yes i kind of did use ai. i used it to make sure my wiring was correct by providing chatgpt screenshots and asking for feedback.
2) is there bluetooth?
   - yes the esp32 module im using has inbuilt bluetooth so i can connect my bluetooth headphones.
3) does it have storage?
   - yes ive put a sd card module and i will insert a sd card into it with my songs already loaded.
4) does it have wifi?
   - ayes the esp 32 module im using also has wifi.
5) can you listen to songs that you havent downloaded?
   - yes using wifi , i can build a ui and load all my songs into my home server and listen to music while connected to wifi anywhere i am.
6) what would happen if i run out of storage
   - i can load the songs that i am not able to download onto my home server and listen to it when the device is online.
7) how do you load songs onto it
   - you can load the songs onto the sd card or you could upload it onto the sd card via bluetooth or wifi using the esp32 module.
